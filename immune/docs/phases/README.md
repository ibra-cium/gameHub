# docs/phases

The build plan. Work through these in order. Each ticket contains a prompt written to be pasted into the agent as-is.

## Files

| File | What it does |
|------|--------------|
| `phase-00-foundation.md` | Split the single file into ES modules and set up documentation. No gameplay change. |
| `phase-01-two-health-bars.md` | Host vitality, cheap player death, marrow respawn, heartbeat audio. |
| `phase-02-blob-identity.md` | Weakened enemies, engulf, mass trade-off, vent. |
| `phase-03-level-engine.md` | Data-driven levels and all six objective types. |
| `phase-04-act1-skin.md` | Act I content, levels 1–12, splitting bacteria. |
| `phase-05-act2-bloodstream.md` | Act II content, levels 13–28, currents, virus infection, parasite theft. |
| `phase-06-to-09.md` | Meta progression, the descent systems, acts III–VII, game feel and ship. |

## Notes

**Phases 0–6 produce a complete, shippable game.** 28 levels, both health bars, mutations, saving.

Phase 8 is where levels 29–100 get written, and it is almost pure content.

Do not start Phase 8 before Phase 6 is finished and levels 1–28 are actually fun. See `CONTEXT.md` section 14.

Ticket risk levels: tickets marked HIGH RISK should be run in Antigravity's Planning mode with `thinking_level: HIGH`.
